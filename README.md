# Do Not Pass Go Banker

A Banker app to replace paper bills on board games. A specific board game has been kept in mind while developing.

## Legal disclaimer

This app is a standalone open-source utility created under educational and personal scopes.  
This app nor its developer has nothing to do with the game you're thinking of.

## Changelog and future plans

The full changelog and the future plans can be found in their own files on the main directory of the source code.
The future plans also include known bugs.

## Install

You can install this app from autogenerated `.exe` (for Windows) or `.dmg` (for Mac). These can be found in GitHub Releases here:

https://github.com/joniflink/do-not-pass-go-banker/releases

## Running from source code

If you for some reason want to, the app can be run also from source code:

1. Clone this repo.
2. Install Maven.
3. Run:

```bash
mvn clean compile exec:java -Dexec.mainClass="Main"
```
