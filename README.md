# Do Not Pass Go Banker

A Banker app to replace paper bills on board games. A specific board game has been kept in mind while developing.

## Legal disclaimer

This app is a standalone open-source utility created under educational and personal scopes.  
This app nor its developer has nothing to do with the game you're thinking of.

## Running from source code

1. Clone this repo.
2. Install Maven.
3. Run:

```bash
mvn clean compile exec:java -Dexec.mainClass="Main"
```
